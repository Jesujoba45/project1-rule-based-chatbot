# Rule-Based AI Chatbot

## Project Overview
This project is a simple rule-based AI chatbot developed using Python. The chatbot responds to predefined user inputs using conditional logic and dictionary-based responses.

## Objective
The objective of this project is to simulate human interaction through predefined conversational responses.

## Features
- Handles greetings
- Responds to predefined questions
- Runs continuously using a loop
- Handles unknown inputs
- Supports exit commands

## Technologies Used
- Python

## Concepts Used
- Rule-Based AI
- Conditional Logic
- Dictionary Mapping
- User Input Handling

## How to Run

Run:

```bash
python chatbot.py
```

## Example Inputs
- hello
- hi
- how are you
- thanks
- bye
- exit
